## Overview

Tunnels — especially Alpine mountain tunnels — impose restrictions beyond standard national driving rules. These include height and weight limits, dangerous goods restrictions (ADR tunnel categories), one-way convoy systems, advance booking requirements, and special night/weekend rules. For operators routing through Alpine corridors (SE→IT, DE→IT, FR→IT, AT→IT), understanding tunnel-specific restrictions is essential to avoid delays and non-compliance.

Separate from physical tunnel restrictions, the **ADR tunnel classification** (A/B/C/D/E) defines what dangerous goods may transit via which tunnels — this applies to ALL road tunnels on the ADR network, not just major Alpine tunnels.

---

## ADR Tunnel Categories (All Road Tunnels)

Applies to any tunnel listed in ADR Annex 7 (ADR Agreement). Categories restrict transport of goods based on their hazard potential:

| Category | Restriction | Notes |
|---|---|---|
| **A** | No restriction on dangerous goods | All ADR goods permitted |
| **B** | Explosives (Class 1, div. 1.1/1.2/1.3) and certain other high-hazard goods restricted | Most goods transit freely |
| **C** | Category B goods + additional Class 3 flammable liquids, Class 2 gases | Petrol tankers may be restricted |
| **D** | Category C goods + additional restrictions | Significant restrictions on flammable/toxic goods |
| **E** | All dangerous goods prohibited except in limited quantities and certain exempted goods | Strictest tunnels |

**Key rule:** Drivers must check the ADR tunnel category for every tunnel on their route when carrying dangerous goods. Violations result in prohibition + prosecution.

## Major Tunnels — Detailed Restrictions

### Gotthard Road Tunnel (CH) — 16.9 km

| Parameter | Detail |
|---|---|
| Location | Airolo (UR) to Göschenen (UR), Switzerland |
| Height limit | **4.80 m** (reduced during roadworks) |
| Width | 8.0 m (two-lane) |
| Weight | No specific tunnel weight limit (standard Swiss rules apply) |
| ADR category | **E** — all dangerous goods prohibited (except exempted limited quantities) |
| Speed limit | **80 km/h** (reduced to 60 km/h in convoys) |
| Convoy system | **YES** — during peak periods (weekends, summer) vehicles are grouped in convoys with police escort or convoy leader |
| Convoy frequency | Every 30–60 minutes during peak |
| Wait times (peak) | Up to 4+ hours at weekends in summer |
| Alternative | Gotthard Rail Tunnel (passenger + car train — ROLA/Rail Motorway for trucks) |
| Operator | Federal Roads Office (ASTRA) |

**Planning note:** During summer weekends, the Gotthard queue can exceed 30 km. Plan for the rail alternative (Autoverlad) or transit through the San Bernardino Tunnel (A13) as alternative, noting it has its own restrictions.

---

### Mont Blanc Tunnel (FR/IT) — 11.6 km

| Parameter | Detail |
|---|---|
| Location | Chamonix (FR) to Courmayeur (IT) |
| Height limit | **5.0 m** (reduced during heavy goods convoy mode) |
| Width | 8.6 m |
| ADR category | **E** — dangerous goods prohibited (strict regime since 1999 fire) |
| Speed limit | **70 km/h** |
| System | **One-way convoy system** — alternating direction at intervals |
| Convoy direction | Alternates every 30 minutes (typically) |
| Convoy size | Maximum 150 vehicles per convoy |
| Night closure | 23:00–06:00 for heavy trucks in certain periods |
| Booking | Mandatory pre-booking for heavy vehicles: https://www.tunnelmontblanc.com |
| Operators | ATMB (FR) + SITMB (IT) |

**Post-1999 fire measures:** Strict safety checks before entry; vehicles with fuel leaks, brake defects, or ADR non-compliance turned away; temperature sensors throughout.

### Eurotunnel / Channel Tunnel (FR/GB) — 50 km

| Parameter | Detail |
|---|---|
| Location | Folkestone (GB) to Coquelles/Calais (FR) |
| ADR category | **B** (for dangerous goods in shuttle trains) |
| Speed | Shuttle train — not a road tunnel |
| Dangerous goods | Strictly regulated; must declare in advance; many ADR classes prohibited; specific rules for each class |
| Height limit | **1.85 m (cars)** — no restriction for HGV Le Shuttle Freight |
| Width | No practical restriction for Le Shuttle Freight trucks |
| Booking | Mandatory advance booking for freight: https://www.eurotunnel.com/uk/freight/ |
| Dangerous goods declaration | At least **24 hours in advance** for any ADR goods |
| Prohibited in tunnel | Class 1 explosives, Class 7 radioactive, certain flammable gases (LPG) |

## Height Restrictions Summary

| Tunnel | Max height | Country |
|---|---|---|
| Eurotunnel (freight shuttle) | No practical limit | FR/GB |
| Fréjus | 5.1 m | FR/IT |
| Mont Blanc | 5.0 m | FR/IT |
| Gotthard | 4.8 m | CH |
| Tauern | 4.5 m | AT |
| Arlberg | 4.5 m | AT |
| San Bernardino | 4.5 m | CH |

Standard EU vehicle height limit = 4.0 m, so all listed tunnels accommodate standard vehicles. Extra-tall vehicles (4.0–5.1 m) must verify per-tunnel limits.
