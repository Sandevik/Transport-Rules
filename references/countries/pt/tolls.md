# Portugal — Road Tolls (Via Verde / PT Tolls)

**EU Baseline:** Not applicable — toll systems are national.

**Sources:**
- https://www.pttolls.com/en — PT Tolls / Via Verde: Portuguese toll system

**Last verified: 2026-06-01**

## Overview

Portugal has an extensive **motorway toll network** on its A-roads (autoestradas). Most motorways are concession-operated. Portugal uses the **Via Verde** electronic toll system, which is EETS-compatible. All major Portuguese motorways have tolls; there is no vignette for HGVs.

---

## Vehicle Classes and Rate Structure

Portuguese tolls use a vehicle class system based on axle count. There is **no emission class differentiation** in Portuguese tolls as of 2026.

| Class | Vehicle type | Typical avg. EUR/km |
|-------|-------------|---------------------|
| Class 3 | 2-axle HGV >3.5t | ~€0.076/km |
| Class 4 | 3-axle combination | ~€0.110/km |
| Class 5 | 4-axle combination | ~€0.135/km |
| Class 6 | 5+ axle combination (5-axle artic) | ~€0.160/km |

**Key route examples (Class 6 = 5-axle artic):**

| Route | Distance | Approx. total | Avg. €/km |
|-------|----------|--------------|-----------|
| A1 Lisbon–Porto | 314 km | ~€48 | €0.15/km |
| A2 Lisbon–Faro (Algarve) | 280 km | ~€42 | €0.15/km |
| A25 Aveiro–Spanish border | 170 km | ~€25 | €0.15/km |

*Note: Rates vary by concessionaire. Use portagens.infraestruturasdeportugal.pt calculator for exact section tolls.*

## Payment

- **Via Verde transponder** — electronic toll, works at all toll points; EETS-compatible
- **EASYToll** (for foreign/occasional users) — register online before visiting Portugal at pttolls.com
- **Credit/debit card** at toll booths
- Electronic ANPR (plate recognition) for unregistered foreign vehicles — invoice sent to keeper

**PT Tolls** portal for foreign operators: https://www.pttolls.com/en
